# NAME Deep-Dive LOADOUT v0

**Status:** durable research-world slice; no new authority surface.

## Purpose

Compile the smallest bounded world capable of investigating the NAME-of-JESUS corpus without letting tool availability, later reception, or experimental decoders silently widen evidence or effect authority.

## Core law

```text
RESEARCH WORLD != SOURCE WORLD
BINDING != EVIDENCE
DECODER AVAILABILITY != DECODER ADMISSION
READ REACH != PUBLICATION AUTHORITY
```

## Proposed profile

```text
loadout.name-of-jesus/v0
```

### Required capabilities

- ALEX: attestation, transformation ancestry, research pressure, refusal.
- 3rdi: observer-local cut/projection.
- source adapters: read-only retrieval only.

### Optional bounded capabilities

- Dogram: deterministic decoder comparison and residual calculation.
- Wolfram: declared mathematical calculation/verification.

## Source-world fence

The compile may carry source worlds A/B/C/D as separate declared context partitions:

- A — Hebrew Bible / Second Temple Jewish world
- B — earliest Jesus movement / New Testament
- C — early material Christianity
- D — later reception

Their co-presence in one research compile does not make evidence cross-world by default. ALEX owns any later bridge evaluation.

## Effect fence


## Decoder binding rule

A numeric decoder may bind only as a representation/calculation capability. Its output must identify the exact consumed ALEX carrier/transform digest and decoder identity.

```text
ROUTER CHOICE != EVIDENCE
DECODER OUTPUT != SOURCE IDENTITY
```
